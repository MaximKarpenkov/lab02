## 1. Прогноз результатов (Задание 3)

| Выражение | Прогноз вручную | Результат Python | Объяснение |
|---|---|---|---|
| `2 + 3 * 4` | 14 | 14 | Сначала умножение, потом сложение. |
| `(2 + 3) * 4` | 20 | 20 | Скобки меняют приоритет: сначала сумма, потом умножение. |
| `17 // 5` | 3 | 3 | Целочисленное деление (округление вниз). |
| `17 % 5` | 2 | 2 | Остаток от деления. |
| `-7 // 2` | -4 | -4 | `//` округляет **вниз** (к минус бесконечности), а не к нулю. |

## 3. Ответы на вопросы для защиты

1. **Отличие `/` от `//`:**
   * `/` — вещественное деление (возвращает `float`, например `7 / 2 = 3.5`).
   * `//` — целочисленное деление с округлением вниз (возвращает `int`, например `7 // 2 = 3`).

2. **Смысл остатка (`%`):**
   Это то, что остаётся после выделения целой части. Связь: `a = (a // b) * b + a % b`. Например, `17 = 3 * 5 + 2`.

3. **Почему форматирование не устраняет неточность `float`:**
   Формат `:.2f` только меняет **отображение** числа на экране (округляет визуально), но не меняет само хранимое значение в памяти. Например, `0.1 + 0.2` равно `0.30000000000000004`, и `:.2f` покажет `0.30`, но если это число использовать дальше в расчётах, ошибка сохранится.
